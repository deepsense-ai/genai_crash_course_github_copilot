## Introduction

This chapter is about using GitHub Copilot as a practical coding assistant.

- It works directly inside Visual Studio Code.
- It reduces context switching between coding and asking questions.
- It helps you move from idea to working prototype faster.

The main value is speed without leaving your development workflow.

---

## One interface for multiple LLMs

Copilot is not just one fixed LLM.

Different LLMs can be available depending on the plan and the tool you use.

- some LLMs are faster
- some LLMs reason better
- some LLMs are stronger for complex coding tasks

This flexibility matters when you want the tool to match the task instead of forcing one workflow.

---

## Inline and chat interface

For most beginners, the two main features are inline suggestions and chat.

Inline suggestions act like smart autocomplete inside the editor.

Copilot Chat lets you:

- ask for explanations
- generate code
- refine an idea
- fix an error without leaving VS Code

This makes the workflow more natural, especially when you do not want to write everything from scratch.

---

## Copilot CLI for terminal workflows

Copilot support is not limited to the editor.

You can also use it in terminal workflows for:

- command suggestions
- debugging help
- project changes outside the editor
- development workflow support

The key point for this workshop is simple: Copilot lowers the barrier to building software, but it works best when the human stays in charge.
